# Web Dashboard

## Setup

```bash
cd web-dashboard
npm install
```

## Pokretanje

```bash
npm start
```

Web će biti dostupan na `http://localhost:3000`

## Features

✅ PIN Search
✅ Rezultati sa detaljima
✅ Hardware Informacije
✅ FiveM Modovi/Scripti
✅ Status Indikator
✅ Risk Score
✅ Responsive Design
