# Maroko AC Desktop App

## Setup

1. Otvori `MarokoacFiveM-PCCheck.sln` u Visual Studio
2. Build solution (Ctrl + Shift + B)
3. Run (F5)

## Features

✅ Cool Gaming Menu
✅ PC Hardware Scan
✅ FiveM Mod/Script Detection
✅ PIN Generator (6 digits)
✅ Upload Results to Web

## Build EXE

```bash
Publish > Release > Create EXE
```

EXE će biti dostupan u `bin/Release/` direktorijumu.
